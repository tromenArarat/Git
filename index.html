GUIA DE ERRORES

Ø ERROR DE SINTAXIS

¿Que es? No se siguen las reglas del lenguaje utilizado. El programa NO PUEDE EJECUTARSE.

Ejemplo: si x menorQue 5 entonces (deberia ser x < 5)

Como corregirlo: Revisar ortografia de palabras clave, operadores, estructura de bloques (finsi, fin_mientras), comillas en textos, parentesis.

Accion: Comparar con la sintaxis correcta de PSeInt.

Ø ERROR DE EJECUCION

¿Que es? El programa arranca pero se DETIENE por una operacion imposible en tiempo de ejecucion.

Ejemplo: resultado = 100 / 0 (division por cero)

Como corregirlo: Validar datos de entrada (evitar division por cero o raiz cuadrada de negativos), verificar indices de listas, inicializar variables, evitar bucles infinitos.

Accion: Agregar controles condicionales antes de operaciones riesgosas.

Ø ERROR LOGICO

¿Que es? El programa CORRE pero da un RESULTADO INCORRECTO. Es el mas dificil de detectar.

Ejemplo: promedio = suma * 3 (deberia ser suma / 3)

Como corregirlo: Revisar formulas matematicas, condiciones de comparacion (>=, >, <), operadores logicos (y/o), inicializacion de acumuladores.

Accion: Probar con casos conocidos y verificar resultados esperados.
