GUÍA DE ERRORES

Ø ERROR DE SINTAXIS

¿Qué es? No se siguen las reglas del lenguaje utilizado. El programa NO PUEDE EJECUTARSE.

Ejemplo: si x menorQue 5 entonces (debería ser x < 5)

🔧 Cómo corregirlo: Revisar ortografía de palabras clave, operadores, estructura de bloques (finsi, fin_mientras), comillas en textos, paréntesis.

Acción: Comparar con la sintaxis correcta de PSeInt.

Ø ERROR DE EJECUCIÓN

¿Qué es? El programa arranca pero se DETIENE por una operación imposible en tiempo de ejecución.

Ejemplo: resultado = 100 / 0 (división por cero)

🔧 Cómo corregirlo: Validar datos de entrada (evitar división por cero o raiz cuadrada de negativos), verificar índices de listas, inicializar variables, evitar bucles infinitos.

Acción: Agregar controles condicionales antes de operaciones riesgosas.

Ø ERROR LÓGICO

¿Qué es? El programa CORRE pero da un RESULTADO INCORRECTO. Es el más difícil de detectar.

Ejemplo: promedio = suma * 3 (debería ser suma / 3)

🔧 Cómo corregirlo: Revisar fórmulas matemáticas, condiciones de comparación (>=, >, <), operadores lógicos (y/o), inicialización de acumuladores.

Acción: Probar con casos conocidos y verificar resultados esperados.
💡 Cada error tiene explicación detallada al responder
